在Windows PowerShell中，从仓库根目录执行下面的兼容准备，即可为核心Q1/Q2/Q3脚本恢复原数据布局。只创建本地硬链接，不修改原始附件；该兼容目录已加入忽略规则。

```powershell
$legacyData = Join-Path (Get-Location) '2026年第七届MathorCup数学应用挑战赛—大数据竞赛初赛赛题/2026年MathorCup大数据挑战赛-赛道A初赛/附件'
New-Item -ItemType Directory -Path $legacyData -Force | Out-Null
foreach ($name in @('1.csv','2.csv','3.xlsx','4.csv','5.csv','6.csv','7.csv','8.xlsx','数据说明.txt')) {
    $target = Join-Path $legacyData $name
    if (-not (Test-Path -LiteralPath $target)) {
        New-Item -ItemType HardLink -Path $target -Target (Join-Path (Get-Location) $name) | Out-Null
    }
}
```
