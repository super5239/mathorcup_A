# 解题思路（初稿，供讨论）

## 0. 数据预处理（三问共用）
1. **统一尺度**：1.csv 中 37 列已是 log10，另 33 列为原始浓度 → 统一做 log10(x + ε)，ε 取该列最小正值的一半（处理 0 值）。
2. **缺失值**：73 个缺失（集中在 amyl.acetate、methylpyrazine、X2.3.butanedione 等）。
   主方案 KNN 插补（k=5，同风格优先），对照中位数 / MICE，比较对下游 R² 的影响。
3. **异常值**：稳健 z-score（中位数 / MAD），|z|>5 做缩尾（winsorize），不直接删样本（样本量只有 250）。
4. **对齐**：1.csv 与 4.csv 按 `beer` 编号合并；2.csv、6.csv 的化合物全名通过 8.xlsx「Sensory thresholds」的 field_name_R ↔ chemical_name 映射到 1.csv 列名。
5. **标准化**：建模前对特征做 z-score。

## 问题1：数据缺失条件下的感官评分（化合物 → 0–6 分）
**目标**：输入化合物谱，输出 3.xlsx 中 Aroma 15 项 + Flavour 15 项 + 其余缺陷/口感项（共 50 项）的 0–6 分。

1. **回归模型（连续值）**：X = 1.csv 化合物，Y = 4.csv 50 个标准化感官值。
   - 候选：多输出 GBM / XGBoost、随机森林、PLS 回归、Ridge；5 折交叉验证选模型，报告每个属性的 R² 和 Spearman ρ。
   - 可用「链式回归」利用感官属性之间的相关（5.csv），例如先预测 A_malt_all 再预测其子项。
2. **连续值 → 0–6 分**（关键难点，4.csv 没有原始 0–6 分）：
   - 方案 A（分位数映射）：每个属性的标准化值存在大量相同的最小值（= 原始 0 分），先把它映射为 0；
     其余样本按经验分位数切成 1–6 级。
   - 方案 B（反标准化）：假设原始分 s = μ + σ·z，利用「最小值对应 0 分」「取值离散为 0.5 或 1 的间隔」两个约束，
     从 4.csv 每列取值的离散间隔反推 σ 和 μ，再四舍五入到 0–6。（需先检验 4.csv 每列取值是否呈等间隔离散）
   - 也可直接训练有序回归（ordinal logistic）或分类模型，用加权 Kappa（QWK）评估。
3. **填表**：把 beer 1–12 的预测分数写入 3.xlsx 的 12 张评分卡和 summary。
4. **缺失鲁棒性实验**（对应题目「数据缺失条件下」）：
   随机遮掉 10% / 20% / 30% / 50% 的化合物值 → 插补 → 预测，画「缺失率–准确率」曲线；
   再做「按类别整块缺失」（例如缺全部萜类）看哪类化合物最不可缺。
5. **产出图表**：各属性 R² 柱状图、预测 vs 真实散点、缺失率曲线、12 款啤酒的感官雷达图。

## 问题2：化合物–风味分析（每个感官维度 Top-3 化合物）
1. **共表达图**：以 2.csv 为邻接矩阵，|ρ| > 0.5~0.6 连边（阈值用无标度拟合 R² 或网络密度选择）。
   - Louvain 社区检测 → 化合物模块（预期：酯类/醇类模块、酒花萜类模块、美拉德/麦芽模块、野生菌模块）。
   - 计算节点度、介数、特征向量中心性，识别枢纽化合物。
2. **三种 Top-3 筛选方法**（为了算方法间 Jaccard）：
   - M1：GBM + SHAP 平均绝对值排序（可与 8.xlsx 中给出的 GBM SHAP 对照）。
   - M2：稳定性选择 Lasso / 弹性网（多次子采样下的入选概率）。
   - M3：图正则化排序：score = |ρ(化合物, 感官)|（6.csv / 自算）× 网络中心性权重；同模块高度共线的化合物只保留代表，避免 Top-3 全是同一模块的「替身」。
3. **稳定性论证**：
   - Bootstrap 200 次，统计每个化合物进入 Top-3 的频率（≥ 0.6 视为稳定）。
   - 三种方法两两 Top-3 的 Jaccard 系数 J = |A∩B| / |A∪B|，做热力图；平均 J 越高结论越可信。
4. **化学合理性论证**：
   - 对照 8.xlsx 阈值表的来源（origin：Hops / Yeast / Malt / Wild flora）和阈值：Top 化合物浓度是否超过感官阈值（OAV = 浓度 / 阈值 > 1 才可能被感知）。
   - 文献对照示例：香蕉 ↔ isopentyl acetate；指甲油 ↔ ethyl acetate；丁香 ↔ 4-vinylguaiacol (4VG)；
     柑橘/花香 ↔ linalool、geraniol；焦糊 ↔ 呋喃/吡嗪类；纸板味 ↔ trans-2-nonenal；黄油味 ↔ diacetyl；乳酸/醋酸 ↔ lactic/acetic acid。
5. **产出图表**：共表达网络图（按模块着色）、感官 × Top-3 表格、bootstrap 频率热力图、方法间 Jaccard 热力图。

## 问题3：风格条件生成与跨风格迁移
1. **风格条件生成模型**：
   - 主方案：条件变分自编码器（CVAE），条件 = tasting_category_fine 的 one-hot（22 类），输入为预处理后的化合物谱。
   - 基线 / 小样本方案：每个风格拟合高斯 copula 或 GMM（Faro 仅 3 个、Brut 4 个样本，需借助相近风格做层次收缩）。
   - 可选：条件 GAN 做对比（样本量小，可能不稳定，作为讨论项）。
2. **生成 Tripel / Kriek / Lambic 化合物谱**，并用问题1模型得到感官画像（雷达图）。
3. **生成质量评估**：
   - 分布距离：生成 vs 真实的 MMD、各化合物的 KS 检验。
   - 风格可辨识度：在真实数据上训练风格分类器，看生成样本被判为目标风格的比例。
   - 相关结构：生成样本的化合物相关矩阵与 2.csv 的差异（Frobenius 范数）。
   - t-SNE / UMAP 图展示真实与生成样本的重合。
4. **跨风格迁移（Pils/Lager → Tripel）**：
   - 编码 Pils 样本得到隐变量 z，沿 Tripel 风格方向移动：z' = z + α·(μ_Tripel − μ_Pils)，换条件后解码。
   - 约束优化：min 与 Tripel 分布的距离 + λ·与原样本的距离，
     s.t. 缺陷化合物 DMS、diacetyl、4VG、trans-2-nonenal、stale hops 相关项 ≤ min(原值, 感官阈值)。
     用投影梯度法实现：每步把超标的缺陷维度投影回可行域。
   - 结果展示：迁移前后的化合物变化 Top-10、感官画像对比、缺陷项前后对比表（证明「不恶化」）。

## 待讨论的决策点
1. 0–6 分映射用方案 A（分位数）还是方案 B（反标准化）？建议先检验 4.csv 的离散性再定。
2. 问题1评分的「约 40 个感官维度」：只做 Aroma + Flavour 的 30 项，还是 50 项全做？（建议 50 项全做，论文重点讲 30 项）
3. 问题3主模型用 CVAE 还是高斯 copula？样本量小，copula 更稳；CVAE 更「像生成模型」，评委观感更好。建议两者都做、互相对照。
4. 7.csv（论坛评论数据）和 8.xlsx 中的价格表目前没用上，可用于：问题1的外部验证（专业品评 vs 消费者评论的一致性），或作为加分讨论。
